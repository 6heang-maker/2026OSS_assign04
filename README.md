# HTML Form Practice

## Key Learning

이번 주에는 HTML Form에 대해 배웠습니다.

1. form과 input을 사용해서 사용자에게 값을 입력받는 방법
2. text, radio, checkbox, date, select, textarea 등 여러 Form 요소 사용 방법
3. CSS를 사용해서 Form 디자인을 변경하는 방법


## Form Elements

이번 과제에서 사용한 Form 요소입니다.

- text : 이름, 전화번호, 주소 입력
- email : 이메일 입력
- radio : 결제 방법 선택
- checkbox : 추가 옵션 선택
- date : 날짜 선택
- select : 지역 선택
- textarea : 요청사항 입력
- color : 색상 선택
- datalist : 연락 가능한 시간 입력
- button : 제출 및 초기화


## HTML vs CSS

form1.html은 HTML Form 구조와 입력 요소를 중심으로 만들었습니다.

form1_css.html은 같은 Form에 CSS를 적용해서
입력창, 버튼, Form 영역 등을 꾸몄습니다.


## Problem & Solution

Form의 입력창 크기가 서로 달라 보이는 문제가 있었습니다.

CSS에서 width를 100%로 지정하고
box-sizing을 적용해서 입력창의 크기를 맞췄습니다.


## Reflection
