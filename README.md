# HTML Form Practice

## Key Learning

이번 주에는 HTML Form을 이용해서 여러 입력 요소를 사용하는 방법을 배웠습니다.

또 CSS를 이용해서 Form의 모양을 꾸미는 방법을 배웠습니다.

## Form Elements

text는 글자를 입력할 때 사용했습니다.

radio는 결제 방법을 선택할 때 사용했습니다.

checkbox는 추가 옵션을 선택할 때 사용했습니다.

date는 날짜를 입력할 때 사용했습니다.

select는 지역을 선택할 때 사용했습니다.

textarea는 요청사항을 입력할 때 사용했습니다.

## HTML vs CSS

form1.html은 Form의 기본 구조를 만들었습니다.

form1_css.html은 같은 Form에 CSS를 적용해서 꾸몄습니다.

## Problem & Solution

입력창의 크기가 서로 달라서 CSS로 크기를 맞췄습니다.
